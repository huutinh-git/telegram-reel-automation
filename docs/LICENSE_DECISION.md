# License decision (maintainer action required)

**This kit intentionally does not add a `LICENSE` file.** A license grants legal rights for other people to copy, modify and distribute your source. The repository owner should make this choice explicitly after confirming authorship and third-party obligations.

Common OSI-approved options:

| License | Key effect (simplified) |
| --- | --- |
| MIT | Permissive: reuse and modification allowed with attribution and the license notice |
| Apache-2.0 | Permissive, with additional express patent license and conditions |
| GPL-3.0 | Copyleft: distributing a derivative generally requires providing corresponding source under GPL-compatible terms |

If you own the code and want simple, broad reuse, **MIT is often suitable**, but this is not legal advice. Verify you have the right to license all included files and that third-party obligations are respected.

To finish licensing, use GitHub's **Add file → Create new file → LICENSE**, choose the approved text from [choosealicense.com](https://choosealicense.com/), use the correct copyright holder and year, commit it, and then update the README to identify the selected license. Merely making a repository public does **not** automatically make it an OSI-licensed project.
